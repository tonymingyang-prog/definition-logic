# 模板映射矩阵（80 页 → 图形元素）

来源：`PPT静态逻辑图模板-完整版 蓝色 by 迟迟.pptx`（80 页，13.33×7.5in）。
另外 23 份是同一套几何的配色/背景变体（6 色 × PPT/WPS × 白/黑底），几何完全一致，见文末「配色与背景映射」。

## 一、怎么读这张表

- **逻辑骨架**：这一页在讲什么关系（中心环 / 分层 / 链路 / 对比 / 生态…），决定用哪种页型。
- **主图母题**：画法（同心环、金字塔、漏斗、蜂窝…），决定用哪些原子。
- **映射原子**：元素库里可直接调用的图形原子 id。
- **映射页型**：`gze_deck` 的图纸类型；`—` 表示还没有对应页型。
- **覆盖**：✅ 原子和页型都齐；◐ 原子有但需要组合/缺变体；✗ 素材库里没有这个母题。
