# 差距分析与升级方案（对照参考模板）

日期：2026-11-22　版本：v0.4

## 一、差距：参考模板 vs 当前实现

拿模板 P03「生态全景」（同心三环 + 维恩 + 相关方）逐项对比：

| 维度 | 参考模板 | 旧实现 | 差距性质 |
|---|---|---|---|
| 面填充 | 每一层都是**浅→更浅的线性/径向渐变**，有体积感 | 单色平涂（t1/t2 交替） | **后端能力缺失** |
| 边缘 | 形状带**柔和外发光 / 投影**，边界不生硬 | 1px 实线描边 | **后端能力缺失** |
| 文字 | 扇区标签**沿弧逐字排布**，字头朝外 | 整段文字旋转一个角度 | 实现缺失（已补） |
| 层次 | 3–4 级明度差 + 白色分隔线 + 虚线环 | 只有 2 级明度 | 配色策略简单 |
| 装饰 | 外圈虚线光环、端点圆点、弧形引导线 | 有，但无光晕 | 细节 |
| 图标 | 每个节点配线性图标 | 纯文字圆 | **资源缺失** |
| 排版 | 手调光学间距，标签避让 | 等角均分 | 算法简单 |

**为什么一直达不到**：不是排版参数没调好，是**导出后端只能平涂**——
`python-pptx` 的公开 API 没有渐变/发光/阴影，旧代码在 `apply_fill` 里把 `fillGrad` 直接退化成纯色，`no_shadow` 还主动删掉了 `p:style`，所以无论前端画多细，导到 PPT 只有色块。

## 二、调研（别人怎么做的）

1. **python-pptx 本身支持渐变**（1.0 起）：`fill.gradient()` → `gradient_stops[].color` → `gradient_angle`，底层写的是 `<a:gradFill><a:gsLst>`。文档与 XML 样本见 [python-pptx Gradient Fill](https://python-pptx.readthedocs.io/en/stable/dev/analysis/dml-gradient.html)。
2. **发光/阴影没有 API，但 OOXML 支持**：`<a:effectLst><a:glow rad="…"><a:srgbClr>…</a:srgbClr></a:glow>`、`<a:outerShdw blurRad dist dir>`。做法是往 `spPr` 里注入 XML —— 这也是社区通行做法（officegen / pptxgenjs 都是直接拼 OOXML）。
3. **反向转换项目**（如 GitHub 上的 [ppt-master](https://github.com/hugohe3/ppt-master)）把 OOXML 的 `gradFill` 映射成 SVG 的 `<linearGradient>`；说明**两套后端用同一份渐变描述**是可行且必要的。
4. **文字沿路径**：PowerPoint 原生不支持 text-on-path，业界做法是**逐字定位 + 逐字旋转**（SVG 用 `<textPath>` 才行）。我们采用逐字方案，PPT 里可编辑。
5. **径向渐变**：OOXML 支持 `path="circle"` 的 gradFill，但 PowerPoint 与 WPS 渲染差异较大，社区普遍用「线性渐变 + 多层圆叠加」近似。

## 三、这次改了什么（v0.4）

### 1. 后端补齐三种效果

| 效果 | scene 写法 | SVG | PPTX |
|---|---|---|---|
| 线性渐变 | `fillGrad: { from, to, angle }` | `<linearGradient>`（支持角度） | `<a:gradFill>`（`gradient_angle`） |
| 外发光 | `glow: { color, radius, opacity }` | `<filter><feGaussianBlur>` | `<a:effectLst><a:glow>` |
| 投影 | `shadow: { color, blur, dist, dir }` | 同上（合并滤镜） | `<a:outerShdw>` |

同一份场景 JSON，两条通道都出效果；**PPTX 里仍是原生形状**，渐变可在 PowerPoint/WPS 里继续调。

### 2. 环形体系重画

- 中圈扇区：**渐变填充**（浅→更浅，按扇区角度定向）+ 2px 白色分隔
- 扇区标签：**沿弧逐字**（字头朝外，下半圈自动翻向），不再是一段文字转个角度
- 中心：渐变圆环 + 白芯 + 柔和发光
- 外圈节点：白→浅渐变 + 轻投影 + 虚线光环
- 外圈底盘：整圈淡蓝底 + 细描边

### 3. 仍然差的（诚实）

- **图标**：模板每个节点有线性图标，我们只有文字。要补需要一套 SVG 图标库（约 60 个），工作量大。
- **径向渐变**：目前只有线性；中心球体的体积感靠「渐变环 + 白芯」近似。
- **光学间距**：仍是等角均分，长标签在窄扇区里会挤（如「薪酬福利」）。
- **手绘感装饰**：模板的花瓣形外框、细刻度没有做。

## 四、下一步（按性价比排序）

1. **图标库**：内置 60 个线性图标（SVG path），支持 `icon: 'users'` 槽位 —— 视觉提升最大。
2. **径向渐变**：给 `fillGrad` 加 `type: 'radial'`，PPTX 用 `path="circle"`，SVG 用 `<radialGradient>`。
3. **标签避让**：按弧长自动缩字号 / 断行。
4. **暗色主题**：黑色背景模板（12 份）需要一套反色调色板。
