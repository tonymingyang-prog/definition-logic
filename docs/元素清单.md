# 35 个图形原子

按 6 个分类组织。每个原子都是**参数化**的：给定框（x/y/w/h）与槽位内容，按同一套几何绘制，可导出原生 PPTX 或 SVG。

> 尺寸是设计空间 px（1280×720 画布）。实际使用时按目标框缩放，字号随框等比缩放。
