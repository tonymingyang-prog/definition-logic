# 版面规格与选型指南

这份文件是「定义逻辑」的版式契约：什么时候用哪张图纸、字号多大、元素多大、一页能放多少字。
数值来自三份参考版式（数智员工方案 / 华为一网通 / 80 页静态逻辑图模板）的量测，并已在 v2 生成器里落地。

## 一、画布与页边距

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 1280 × 720 px（= 13.33 × 7.5 in，96dpi） | 16:9 |
| 左右边距 | 44 px | 参考模板 26–39 px，方案汇报取 44 |
| 标题区 | 32–128 px | 眉标 32，标题 50，副说明 103，分隔线 128 |
| 正文区 | 146–618 px | 主图 + 辅助块都在这条带里 |
| 结论条 | 628–672 px | 浅底 + 左侧 3px 主色竖条 + “结论”小标 |
| 页脚 | 692 px | 左页名、右页码、章节进度点 |

## 二、字号阶梯（设计 px；PPT 里 = px × 0.75 pt）

| 角色 | 字号 | 字重 | 用在哪 |
|---|---|---|---|
| 封面主标题 | 48 | 700 | 封面，最多 2 行 |
| 章节大号 | 78 | 700 | 章节页序号 01–04 |
| 收尾标题 | 42 | 700 | 收尾页，最多 2 行 |
| 页标题 | 31 | 700 | 每页结论句，**单行**，≤ 32 个汉字 |
| 章节标题 | 36 | 700 | 章节页 |
| 目录标题 | 19 | 700 | 目录条目 |
| 卡片/区块标题 | 13–14.5 | 700 | 侧注、注释块、流程行 |
| 正文/副说明 | 12.5 | 400 | 页头副说明、结论条 |
| 对比项/清单 | 11.5 | 400 | 对比框、V 形流程行 |
| 侧注说明 | 11 | 400 | 主图右侧注释 |
| 页脚 | 9.5 | 400/700 | 页名、页码 |

> 字号不能再往下压：8.6 pt（旧版）在投影和 PPT 里都偏小，参考模板正文最低 10 pt。

## 四、逻辑 → 图纸（选型决策）

| 这一页要讲的关系 | 用哪个页型 | 底层原子 | 一页信息量 |
|---|---|---|---|
| 一个中心 + 周边能力（全景图） | `hub` | `hub.radial` / `medallion` / `arc.fan` | 1 中心 + 6–8 节点 + 3 条侧注 |
| 分层平台（应用/中台/底座） | `disc` / `bands` | `platform.disc` / `layers.band` | 3–4 层 × 3–4 项 |
| 一条链路（数据流、业务流程） | `lanes` | `flow.lanes` / `flow.steps` | 3–4 段 × 3–4 项 |
| 阶段推进（V 形/步骤） | `chevron` | `flow.chevron` | 3–5 段 + 4 行说明 |
| 时间/节奏 | `timeline` | `timeline` | 3–4 节点 + 3–4 卡 |
| 二维分类（域 × 层） | `matrix` | `matrix.grid` | 3×3 上限 |
| 两种做法/两个状态 | `compare` | 卡片列 | 2–3 栏 × 4–5 项 |
| 举措/保障/落地顺序 | `stack` | `stack.list` | 4–5 条 + 3 条侧注 |
| 主体 + 两侧支撑（生态） | `eco` | `eco.bracket` | 1 主体 + 4+4 支撑 |
| 指标/价值 | `kpi` | `card.stat` + `metric.bar` | 4 卡 + 3 条 + 3 注 |
| 层级收紧（战略→执行） | 暂无页型 | `pyramid.levels` | 3–5 层 |
| 转化漏斗 | **缺口** | 待建 `funnel.stage` | — |
| 词云/标签云 | **缺口** | 待建 `cloud.text` | — |

## 五、内容写法

- 每页标题写**结论句**（“四层各自为战，能力在系统间重复”），不写“现状分析”。
- 每个内容页给一条 `conclusion`（20–40 字），画在底部结论条。
- 卡片 = 短标题（≤ 10 字）+ 1 行解释（≤ 24 字）；超过就拆块，不要缩字号。
- 一页最多一个主图；主图之外只放 0–3 个辅助块（指标卡 / 侧注 / 结论条）。

## 六、PPTX 端注意事项

- 字体默认「微软雅黑」；模板原字体是思源黑体 CN，本机无，故不默认。
- 文本框行高与 SVG 差 5–10%，长文案先手动断行。
- 圆形/圆角在 PPT 里是原生形状，可逐块改；SVG 是整图矢量，不能再拆块。
